# [MTK] MT6789 温控参数调整

## 一、变更概要

- **适用平台**：MTK MT6789
- **工程目录**：`mt8781_s/vendor`
- **配置文件**：`mediatek/proprietary/external/thermal_core_lib/mt6789/thermal.conf`

**涉及模块：**
- `[mtk-skin-control]`：皮肤温控策略
- `[charger-cooler]`：充电温控策略

**修改目的：**
- 提高皮肤温控阈值，延后温控介入时机。
- 将充电温控阈值统一调整为 58°C。
- 将充电温控的全部电流档位设置为 `0`。

---

## 二、[mtk-skin-control] 皮肤温控调整

### 1. 参数变更对比

**① `min_target_tj`：最低目标结温**

- 修改前：`55000`（55°C）
- 修改后：`60000`（60°C）
- **调整幅度：+5°C**

**② `trip_tpcb`：PCB 温控触发阈值**

- 修改前：`43000`（43°C）
- 修改后：`54000`（54°C）
- **调整幅度：+11°C**

**③ `target_tpcb`：PCB 目标控制温度**

- 修改前：`46000`（46°C）
- 修改后：`58000`（58°C）
- **调整幅度：+12°C**

**④ `max_target_tj`：最高目标结温**

- 修改前：`85000`（85°C）
- 修改后：`85000`（85°C）
- **调整幅度：不变**

### 2. 参数作用说明

#### min_target_tj：最低目标结温

该参数表示皮肤温控环路允许下调的最低 SoC 目标结温。

将其从 55°C 提高至 60°C 后，即使设备壳温较高，温控策略也不会将目标结温下压至 60°C 以下。

**调整影响：** 减少温控对 SoC 性能的干预，使整体温控策略更加偏向性能优先。

#### trip_tpcb：PCB 温控触发阈值

该参数用于控制 PCB 温度达到指定阈值时的温控介入条件。

将触发阈值从 43°C 提高至 54°C，使设备需要达到更高的 PCB 温度才会进入皮肤温控介入区间。

**调整影响：** 延后温控介入时机，减少因温度升高而提前触发的性能限制。

#### target_tpcb：PCB 目标控制温度

该参数用于设置 PCB 温控环路的目标温度。

将目标温度从 46°C 提高至 58°C，允许温控策略在更高的 PCB 温度范围内运行。

**调整影响：** 放宽稳态控温目标，减少温控调节对设备性能的影响。

### 3. 调整效果

本次修改整体提高了皮肤温控的触发阈值与目标控制温度，使温控策略由相对保守的控制方式调整为更加偏向性能的控制方式。

## 三、[charger-cooler] 充电温控调整

### 1. 修改前配置

原配置采用 **4 档分级温控限流**，根据不同的温度阈值调整充电电流。

```c
threshold  = [40000, 42000, 45000, 56000]  // 40°C / 42°C / 45°C / 56°C
hysteresis = [2000,  2000,  2000,  2000]   // 全部 2°C
current    = [1800,  1000,  500,   0]      // 单位：mA
```

**原始配置说明：**

- `threshold`：设置 40°C、42°C、45°C、56°C 四个温控阈值。
- `hysteresis`：各档位温度回滞均为 2°C。
- `current`：对应的电流配置分别为 1800mA、1000mA、500mA、0mA。

### 2. 修改后配置

将全部温控阈值统一调整为 **58°C**，同时缩小温度回滞，并将所有电流档位设置为 `0`。

```c
threshold  = [58000, 58000, 58000, 58000]  // 全部 58°C
hysteresis = [1000,  1000,  1000,  1000]   // 全部 1°C
current    = [0,     0,     0,     0]      // 全部 0mA
```

### 3. 参数变更说明

**① `threshold`：充电温控阈值**

- 修改前：40°C / 42°C / 45°C / 56°C
- 修改后：58°C / 58°C / 58°C / 58°C

**调整说明：** 将原来的 4 档不同温度阈值统一提高至 58°C。

**② `hysteresis`：温度回滞**

- 修改前：全部为 `2000`（2°C）
- 修改后：全部为 `1000`（1°C）

**调整说明：** 将温度回滞从 2°C 缩小至 1°C。

**③ `current`：充电电流档位**

- 修改前：1800 / 1000 / 500 / 0mA
- 修改后：0 / 0 / 0 / 0mA

**调整说明：** 将原有的分级电流配置统一设置为 `0`。

---

## 四、修改总结

### 1. 皮肤温控

- `min_target_tj`：55°C → 60°C
- `trip_tpcb`：43°C → 54°C
- `target_tpcb`：46°C → 58°C
- `max_target_tj`：85°C（保持不变）

**调整方向：** 提高温控阈值，延后温控介入，减少对 SoC 性能的限制。

### 2. 充电温控

- `threshold`：原 4 档温度统一调整为 58°C。
- `hysteresis`：由 2°C 调整为 1°C。
- `current`：所有档位统一设置为 `0`。

**调整方向：** 提高充电温控阈值，统一温控档位参数。

### 3. 整体调整方向

本次修改主要通过提高皮肤温控与充电温控阈值，减少温控策略提前介入的情况，使设备整体温控策略更加偏向性能优先。
