# [MTK] 霍尔驱动（Hall Driver）移植说明

## 1. Kernel Config

---

## 1.1 DTS 配置

### 文件路径

```text
kernel_device_modules-6.1/arch/arm64/boot/dts/mediatek/aiot8391p3_64_bsp.dts
```

### 修改内容

#### 1. 增加 Hall GPIO 配置

```diff
 kpd_gpio: kpd-gpio {
        pins-cols {
-               pinmux = <PINMUX_GPIO44__FUNC_KPCOL0>;
+               pinmux = <PINMUX_GPIO44__FUNC_KPCOL0>,   // 保留原KPCOL0
+                        <PINMUX_GPIO45__FUNC_KPCOL1>;   // 新增KPCOL1
                input-enable;
                bias-pull-up = <MTK_PUPD_SET_R1R0_01>;
        };
```

#### 2. 删除 GPIO45 CAN Standby 配置

```diff
-       pin-can-standby {
-               pinmux = <PINMUX_GPIO45__FUNC_GPIO45>;
-               output-low;
-       };
```

#### 3. 增加 Hall EINT 配置

```diff
+&hall {
+       hall_eint = <&pio 12 0>;      // GPIO12作为Hall外部中断
+};
```

